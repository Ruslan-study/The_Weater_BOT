# 🌤 Minsk Weather Bot

Telegram-бот, который присылает погоду в Минске: утром — на сегодня,
вечером — на завтра. Без внешних зависимостей, без API-ключей погоды.

## Возможности
- ☀️ Утренняя сводка (текущая погода + прогноз по частям суток)
- 🌙 Вечерний прогноз на завтра
- ⚙️ Настройка времени рассылки (пресеты)
- 🔕 «Тихий режим» — вечером пишет только если завтра дождь/снег
- 📊 Один запрос к API на всех подписчиков в цикле рассылки

## Стек
- Python 3 (стандартная библиотека: `urllib`, `json`, `threading`)
- Telegram Bot API
- Open-Meteo API (бесплатно, без ключа)

## Запуск
1. Получите токен у [@BotFather](https://t.me/BotFather)
2. `export BOT_TOKEN="ваш_токен"`
3. `python weather_bot.py`

## Архитектура
- `main()` — long polling Telegram, обработка кнопок
- `scheduler_loop()` — фоновый поток, раз в минуту проверяет, кому пора слать
- `fetch_weather()` — один запрос Open-Meteo на 2 дня вперёд
